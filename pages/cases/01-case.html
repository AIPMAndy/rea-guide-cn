01｜自带 Mini App：折扣计算

证据状态：本项目原创样例 / 可本地运行。

用自己拥有源码的 JS 示例解释订单汇总规则，比较 REA 静态模块图与测试。

操作入口： examples/mini-app/README.md。

实验任务书

  1. 目标只针对一个功能，记录当前目标程序版本、授权与前提。
  2. 准备可公开、可合法运行的输入和对应预期输出。
  3. 用 REA MCP 或 CLI 获取真实证据位置，区分静态输出和运行观察。
  4. 对照来源做一组正常、边界和失败样本。
  5. 输出 Evidence 表、猜测、反证和独立实现范围。

验收

  • 本人有分析目标的授权。
  • 命令、版本、输出位置可以供别人复现。
  • 每个结论都能指向原始证据。
  • 不复用未授权的目标源码、素材、商标或凭证。
