# REA 证据等级与可复现口径（2026-10-21）

该手册由 AI 酋长 Andy 独立编辑，非 REA 官方。

| 类型 | 符号 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| 官方功能或正式文档 | **O** | 上游 README、官网描述该能力 | 当前 npm 包、当前操作系统或用户机器一定可用 |
| 自有代码与本地测试 | **T-local** | 这份自带的测试样例在当前环境正确运行 | 真正 REA 分析引擎已分析目标 |
| 真实 REA 运行记录 | **T-REA** | 保存了版本、命令、哈希、输出和源证据的真实分析 | 在所有系统、版本也必然一致 |
| 教学实验方案 | **E** | 一条可执行的实验计划 | 已成功执行或得到 Evidence |
| 不确定或缺少来源 | **U** | 明确知道目前没有充分证据 | 不能写成确定事实 |

## 提交 T-REA 记录必须齐全

1. 目标的版权/合法授权说明、版本、SHA256，必要时脱敏。
2. REA 与 Node 版本、操作系统、Native provider 或辅助工具。
3. 完整只读命令、退出码、执行日期和时区。
4. 可独立核对的原始证据，不上传受保护源码、数据或令牌。
5. 至少一个可推翻主张的反证样本和复测结果。
6. 不得将修改配置或执行未知程序作为默认动作。

官方声明的功能请核对是否包含在本机安装的包内，[上游 README](https://github.com/morluto/rea#what-you-can-analyze) 提醒部分能力可能晚于最新 npm 版本发布。
