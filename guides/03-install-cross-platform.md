## 前置条件

- 只分析自己拥有或获明确许可的目标；不要破解许可证、规避 DRM、探测陌生账号或收集第三方私人信息。
- 先记录操作系统、目标版本、REA CLI/npx 实际版本、Node/npm 版本和分析目标 SHA256。
- 静态线索、运行行为、独立猜测、已测试重建必须各自标注来源。**不把 Agent 的“完成了”当成功证据。**

## 跟着做

1. **第 1 步**：使用各系统官方 Node/npm 安装方式达到 README 的最低版本门槛。
2. **第 2 步**：PowerShell 与 POSIX shell 的变量赋值和 PATH 机制不同，不照搬命令。
3. **第 3 步**：使用官方 npx rea-agents@latest setup，并审查写入配置。
4. **第 4 步**：Linux 的 Ghidra、JADX、JS 静态分析等任务可能依赖 procps 兼容的 ps。
5. **第 5 步**：先用 doctor 检查指定客户端或 provider，而不是盲目全局重装。

## 验收清单
