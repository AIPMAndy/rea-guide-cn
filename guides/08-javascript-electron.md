## 前置条件

- 只分析自己拥有或获明确许可的目标；不要破解许可证、规避 DRM、探测陌生账号或收集第三方私人信息。
- 先记录操作系统、目标版本、REA CLI/npx 实际版本、Node/npm 版本和分析目标 SHA256。
- 静态线索、运行行为、独立猜测、已测试重建必须各自标注来源。**不把 Agent 的“完成了”当成功证据。**

## 跟着做

1. **第 1 步**：从自己拥有的 JS 项目或获授权的 Electron 应用开始。
2. **第 2 步**：明确输入是可访问的目录还是 ASAR，尽量保存只读副本和哈希。
3. **第 3 步**：执行官方 analyze-javascript-application 静态命令。
4. **第 4 步**：关注 import 图、模块调用、主渲染进程、IPC 及 native addon 线索。
5. **第 5 步**：把发现映射回一个用户可见功能，并安排行为测试。
