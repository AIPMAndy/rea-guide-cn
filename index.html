01 / QUICK START

第一次用 REA，
先做这五步。

先用自己拥有源码的样例验证安装与分析能力，避免一上来就面对许可、环境与证据混杂的问题。

01

核对 Node

REA 当前官方要求 Node 22.19+、24.11+ 或 26+；检查你的补丁版本。

02

审阅安装

使用上游官方 npm 包，先看 setup 的文件变更计划。

03

接入 Codex

选定所需 Agent，审批变更后重启，检查 MCP 工具。

04

运行自己的样例

项目自带折扣计算 Mini App，无账号、无私密程序。

05

用证据说话

比较源码、REA 返回结果与单测，无法核实的内容写未验证。

TERMINAL / MAC · CODEX
node --version
npm --version
npx rea-agents@latest setup
# 审阅变更并重启 Codex
npx -y rea-agents@latest doctor --json

注意：命令会使用 npm 网络来源，安装前必须查看 REA 官方安装说明及变更计划。查看 Mac 完整安装指南 ↗

03 / EVIDENCE FIRST

逆向最危险的地方，
是猜得像真的。

REA 提供静态/动态线索。只有把函数位置、调用引用、实验行为和反证串起来，结论才具备可复核性。
